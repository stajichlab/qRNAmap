    Fill the table from your FASTQ files. Pick all of them at once: mates are paired by their file names (_R1/_R2, Illumina _S1_L001_R1_001, _1/_2; the rules of the sample sheet page), and one row is added per sample. Then fill in the condition column.

    Or load a sample sheet (the command-line format)

    A tab-separated sheet with the columns sample, fastq1, optional fastq2, and covariate columns (a header name:numeric makes a numeric column). The page matches each fastq1 and fastq2 path to a picked file by its file name; the folder part of the path is ignored. A row whose file was not picked is marked, with a file picker.

    No sheet yet? Make one from your FASTQ file names (opens in a new tab).

      How to count the reads

      Full depth: every read in the files is counted; nothing is subsampled.

      How many reads to count

      The read length sets the largest N of each sample, because longer reads need more memory: 200,000 pairs for reads of up to 101 bases (measured), 75,000 pairs for longer reads (measured with 150-base reads; docs/browser/page-v1-measurements.md). This field can only lower N. Results are a preview of the first pairs, not a full run. For a full run, use the command-line tool.
