qRNAmap

Map bulk RNA-seq reads, count them per gene, and test for differential expression.

Status: under construction. Genome step and quantification tested in headless Chromium, Firefox and WebKit on a CI runner (small fixture genome and reads); memory on full-size reads is not measured yet; results view is not built yet. Step 1 downloads a catalog genome (or reads your FASTA and GFF3) and builds the kallisto index in your browser. Step 2 counts the first read pairs of each sample with kallisto and shows the mapping numbers per sample. There is no count table, plot or download yet.

Open the tool (genome and samples steps)

Make a sample sheet from FASTQ file names: pairs mates and lanes, lets you add treatment columns, and writes the samples.tsv of the tool and the command line.

The button leads to the three steps of the tool. Steps 1 (genome) and 2 (samples) work. Step 3 (results) is locked until it is built.

What qRNAmap is

  • The command-line tool exists today. It wraps kallisto or Salmon (transcript quantification), or HISAT2 with featureCounts (alignment), and then DESeq2.
  • It runs on a laptop or as SLURM jobs on a cluster.
  • The web page (version 1, under construction) will run the quantification step only, for a small preview of your data. It will need no server and no install. Your reads will not leave your computer.

What version 1 of the web page will not do

  • It will not test for differential expression. The command-line tool does that with DESeq2. The page will give a count table, quality plots, and the command that runs DESeq2 with the command-line tool.
  • It will have no alignment mode (HISAT2 and featureCounts). The command-line tool has that mode.
  • It will be a preview. The planned limit is the first 200,000 read pairs of each sample. Every table, plot and file from the page will say so. The limit comes from memory measurements in Chromium, Firefox and WebKit (see the measurements link below).
  • It will not accept an ENA accession typed by the user.
