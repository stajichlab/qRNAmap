qRNAmap

Map bulk RNA-seq reads, count them per gene, and test for differential expression.

The browser version is under development. This page is a placeholder. You cannot run an analysis here yet.

What exists today

  • A command-line tool. It wraps kallisto or Salmon (transcript quantification), or HISAT2 with featureCounts (alignment), and then DESeq2.
  • It runs on a laptop or as SLURM jobs on a cluster.
  • Source, install steps and the validation notes are in the repository.

What is planned

  • The same steps in a web page, with all computation in your browser and no server.
  • A first measurement of the tools in a browser is published in the repository. It covers kallisto, HISAT2, featureCounts and DESeq2, tested in headless browsers on one small yeast data set. DESeq2 in a browser is not decided yet.
