qRNAmap

Map bulk RNA-seq reads, count them per gene, and test for differential expression.

Beta release. The web page and the desktop app work end to end, but they are new: results, file formats and limits may change between versions, and parts are tested only on small data. Check results you publish with the command-line tool (DESeq2). Please report problems on GitHub issues.

Open the tool (beta)

Make a sample sheet from FASTQ file names: pairs mates and lanes, lets you add treatment columns, and writes the samples.tsv of the tool and the command line.

The tool has three steps: 1. genome (download a catalog genome or read your FASTA and GFF3, and build the kallisto index), 2. samples (count the reads of each sample with kallisto), 3. results (count table, quality plots, a quick differential-expression screen, and downloads).

What qRNAmap is

  • The command-line tool wraps kallisto or Salmon (transcript quantification), or HISAT2 with featureCounts (alignment), and then DESeq2. It runs on a laptop or as SLURM jobs on a cluster.
  • The web page runs kallisto in your browser. It needs no server and no install, and your reads do not leave your computer.
  • The desktop app (Linux and macOS) is the same page with kallisto run on your computer: it counts every read at full speed and can run DESeq2 through R.

Limits of the beta web page

  • Differential expression on the page is a quick screen, not DESeq2. Use the command-line tool (or the desktop app with R) for DESeq2; the page writes the command for you.
  • There is no alignment mode (HISAT2 and featureCounts). The command-line tool has that mode.
  • By default the page counts a preview: the first 75,000 to 200,000 read pairs of each sample, a limit set by memory measurements in Chromium, Firefox and WebKit (see the measurements link below). It can also stream all reads, more slowly. Tables, plots and files say which.
  • It does not accept an ENA accession typed by the user.
