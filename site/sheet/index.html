Sample sheet

qRNAmap: make the samples.tsv of the command-line tool and the Analyze page from your FASTQ file names.

1. File names

Only the names are read: the files are not opened and nothing is uploaded. Mates are paired by fixed rules (Illumina _S1_L001_R1_001, _R1/_R2, _1/_2), lanes of a sample are listed together, and sample names are made safe for the sheet. The same names always give the same table.
